个人项目

Assets Management — 静态资源管理工具

  • https://github.com/xifeiwu/lib-node/tree/master/lib/assets-management
  • 基于元数据（SHA1）的静态资源 diff/同步与远程 push/pull，解决 Git 管理大二进制占用双倍空间的问题。

Process Manager — 进程管理工具

  • https://github.com/xifeiwu/lib-node/tree/master/lib/process-manager
  • 封装子进程启动的常用操作，包括进程启停/监控/日志查看与持久化，支持 detached 模式与异常自动重启。

Socks Proxy — SOCKS5 代理工具

  • https://github.com/xifeiwu/lib-node/tree/master/lib/socks
  • 实现了 SOCKS5 协议及一个定制协议，服务端可以支持灵活的转发策略，如根据请求的 host 和 port 进行转发。

Http Proxy — HTTP 请求转发

  • https://github.com/xifeiwu/lib-node/tree/master/lib/http-proxy
  • 实现了转发 HTTP 及 WebSocket 请求的功能，相比 node-http-proxy，支持更灵活的转发定制策略。

Koa Middlewares

  • https://github.com/xifeiwu/lib-net/tree/master/koa/middleware
  • 实现了一些常用的 Koa 中间件。其中中间件 proxy，mock，customize-response，可以用于MITM Server，在到达最终目标之前，对请求进行修改，定制或返回mock数据，对前后端联调过程中的开发和调试非常友好。

Git Admin — 运行在服务端 Git 仓库管理程序

  • https://github.com/xifeiwu/git-admin
  • 用来搭建自有的 Git 服务，支持 SSH 与 HTTP 协议读写代码仓库，可以实现基于用户的更细粒度的权限控制。

Vite Tool — 中心化 Vite 构建工具

  • https://github.com/xifeiwu/vite-tool
  • 解决了 React 项目重复安装 Vite 依赖的问题，通过一个全局指令 vite-tool，读取项目的 vite.config.ts 文件，来实现 Vite 的相关功能。并提供了一些常用的逻辑，比如 404、SPA 页面路由逻辑等。

Busybox — 基础设施工具集

  • https://github.com/xifeiwu/busybox
