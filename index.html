个人项目
Busybox — 自研 TypeScript 基础设施工具集（Monorepo，核心库 2.5 万行+）
三层架构 · 协议自研 · 生产验证（elif.site / CentOS）· CLI 参考

包括了很多常用工具，核心逻辑，包括http request proxy，http body parser, socks5协议，不依赖第三方库。

  • assets-management：基于元数据（SHA1）的静态资源 diff/同步与远程 push/pull，解决 Git 管理大二进制占用双倍空间
  • process manager：无 daemon 的进程启停/监控/日志持久化，支持 detached 模式与异常自动重启。
  • tcp-gateway通过解析tcp第一个数据块的内容，进行协议探测与分发，决定将请求转向http层的koa服务，还是tcp层的socks服务
  • build-install — build 编译 TS → link 链接全局 bin → all 一步完成 → gz 打包 dist 部署
git-admin
git-admin — Node.js 服务端 Git 仓库管理
  • 用来搭建自由的git服务，支持 SSH 与 HTTP 协议读写代码仓库，替代 gitosis 类方案
  • 基于公钥认证与配置文件实现细粒度读写权限，可按仓库、用户灵活授权
vite-tool
vite-tool — 中心化 Vite 构建工具（React 项目）
  • 痛点：多 React 项目各自安装 Vite、配置重复、升级成本高
  • 解决思路：实现一个全局指令vite-tool，通过读取项目根目录下的vite.config.ts文件，来实现vite的相关功能
  • 实现方式：通过将详细需求告诉Claude Code，快速生成一个框架，再对细节进行打磨
