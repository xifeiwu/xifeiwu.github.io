  • https://github.com/xifeiwu/lib-node/tree/master/lib/socks

Http Proxy — HTTP Request Forwarding

  • https://github.com/xifeiwu/lib-node/tree/master/lib/http-proxy

Koa Middlewares

  • https://github.com/xifeiwu/lib-net/tree/master/koa/middleware
  • Common Koa middleware implementations. The proxy, mock, and customize-response middleware can be used in a MITM server to modify, customize, or mock requests before they reach the final destination — useful for frontend/backend integration and debugging.

Git Admin — Server-side Git Repository Manager

  • https://github.com/xifeiwu/git-admin

Vite Tool — Centralized Vite Build Tool

  • https://github.com/xifeiwu/vite-tool

Busybox — Infrastructure Utility Suite
